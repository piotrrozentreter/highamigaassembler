# `gui_intuition` Runtime Specification

**Audience:** the assembly/Amiga-OS implementer (`amigados` agent).
**Purpose:** define exactly which functions must be written in `lib/gui_intuition.s` so that
programs generated by the **GUI Creator** (`guicreator/`) can display and run a real
`intuition.library` window with buttons, string gadgets and labels.

**Target:** AmigaOS 2.0+ (`intuition.library` V37), 68000 default, system-friendly.
No `$DFF0xx` access, no `TakeSystem()`. All rendering goes through the window's `RastPort`.

**Companion documents**

- [GUI_CREATOR.md](GUI_CREATOR.md) — the designer tool and the metadata → assembler mapping.
- [DOS_LIBRARY.md](DOS_LIBRARY.md) — existing `lib/dos.s` style to mirror (own cached bases,
  `link a6,#0`, arguments at `8(a6)`, result in `d0`).
- [GUI_LIBRARY.md](GUI_LIBRARY.md) — the *other*, unrelated bare-metal widget library
  (`lib/gui.s`). `gui_intuition` does **not** replace or depend on it.

> Verify every offset below against the local NDK
> (`NDK3.2/Include/include_i/intuition/intuition.i`, `exec/ports.i`) before shipping.
> The `Window` tail layout differs between V33 and V36+; the fields used here
> (`wd_RPort` 50, `wd_BorderLeft` 54, `wd_UserPort` 86) are stable across all versions.

## 1. Required HAS API surface

This is the complete contract. The generator emits calls to these and nothing else.

```has
// ---- lifecycle -----------------------------------------------------------
extern func GuiInit() -> int;
    // Opens intuition.library V37 + graphics.library. 0 = OK, -1 = failed. Idempotent.

extern func GuiShutdown() -> void;
    // Closes the window if still open, then both libraries, in reverse open order.

// ---- window construction: all Add* calls go BETWEEN Begin and Show --------
extern func GuiBeginWindow(title: int, x: int, y: int, w: int, h: int,
                           idcmp: int, flags: int) -> int;
    // Fills the private NewWindow template. Opens nothing yet. 0 = OK, -1 = busy.

extern func GuiAddLabel(id: int, x: int, y: int, text: int) -> int;
    // Registers a static IntuiText, redrawn on open and on every IDCMP_REFRESHWINDOW.
    // Not a gadget: produces no events. 'id' exists only for GuiSetLabelText().

extern func GuiAddButton(id: int, x: int, y: int, w: int, h: int,
                         caption: int) -> int;
    // Appends a GTYP_BOOLGADGET (GACT_RELVERIFY|GACT_IMMEDIATE) with an
    // auto-generated Border box and a centred IntuiText caption.

extern func GuiAddEditBox(id: int, x: int, y: int, w: int, h: int,
                          buf: int, undo: int, maxlen: int) -> int;
    // Appends a GTYP_STRGADGET. 'buf' and 'undo' must each point at >= maxlen
    // WRITABLE bytes; maxlen counts the terminating NUL.

extern func GuiShow() -> int;
    // Links the gadget list into nw_FirstGadget, calls OpenWindow(), caches
    // RPort/UserPort/signal mask, draws the labels.
    // Returns Window* on success, 0 if OpenWindow failed, -1 on an order violation
    // (called twice, or without a preceding GuiBeginWindow).

extern func GuiCloseWindow() -> void;
    // Forbid, ModifyIDCMP(win,0), drain+reply all pending messages, RemoveGList,
    // CloseWindow, Permit. Idempotent; safe if the window was never opened.

// ---- event loop ----------------------------------------------------------
extern func GuiWaitEvent() -> int;
    // Blocks on Wait(sigmask), takes ONE IntuiMessage, latches class/code/id/mouse
    // into module storage, ReplyMsg's it, returns a GUI_EVT_* class code.

extern func GuiGetEventID() -> int;    // gg_GadgetID of the last event, 0 if none
extern func GuiGetEventCode() -> int;  // im_Code (ASCII for GUI_EVT_KEY)
extern func GuiGetEventX() -> int;     // im_MouseX of the last event
extern func GuiGetEventY() -> int;     // im_MouseY of the last event

// ---- widget access -------------------------------------------------------
extern func GuiGetEditText(id: int) -> int;
    // Returns the si_Buffer pointer of that string gadget, or 0.

extern func GuiSetEditText(id: int, text: int) -> int;
    // Copies a NUL-terminated string into si_Buffer (clamped to maxlen-1),
    // resets si_BufferPos/si_NumChars, refreshes just that gadget.

extern func GuiSetLabelText(id: int, text: int) -> int;
    // Repoints a label's it_IText and repaints it.

extern func GuiEnableWidget(id: int, enable: int) -> int;
    // Toggles GFLG_DISABLED ($0100) and refreshes the gadget.

extern func GuiActivateEdit(id: int) -> int;
    // ActivateGadget(): puts the text cursor in a string gadget.

extern func GuiRedraw() -> void;
    // Full repaint: RefreshGList over the whole list plus all labels.
```

Event class codes returned by `GuiWaitEvent()`:

| Constant | Value | Meaning |
| --- | --- | --- |
| `GUI_EVT_NONE` | 0 | nothing decoded |
| `GUI_EVT_CLOSE` | 1 | `IDCMP_CLOSEWINDOW` |
| `GUI_EVT_BUTTON` | 2 | `IDCMP_GADGETUP` on a bool gadget |
| `GUI_EVT_PRESS` | 3 | `IDCMP_GADGETDOWN` |
| `GUI_EVT_STRING` | 4 | `IDCMP_GADGETUP` on a string gadget (RETURN/TAB) |
| `GUI_EVT_KEY` | 5 | `IDCMP_VANILLAKEY`, ASCII in `GuiGetEventCode()` |
| `GUI_EVT_MOUSE` | 6 | `IDCMP_MOUSEBUTTONS` |
| `GUI_EVT_REFRESH` | 7 | already handled internally; informational |

### 1.1 Why `GuiBeginWindow` / `GuiShow` and not a single `GuiOpenWindow`

Gadgets can be supplied two ways. The generator knows the entire widget set up front, so the
pre-open path is strictly better:

| | `nw_FirstGadget` (pre-open) | `AddGList` (post-open) |
| --- | --- | --- |
| Calls needed | 0 | `AddGList` + `RefreshGList` per batch |
| Rendering | drawn as part of `OpenWindow` | explicit refresh, visible flicker |
| Failure modes | none | forgotten `RefreshGList` → invisible gadgets; wrong count → partial list |
| Removal | `CloseWindow` handles it | `RemoveGList` with a matching count |

Keep `AddGList`/`RemoveGList` internal, for a future dynamic-widget feature.

### 1.2 Mandatory call order

```
GuiInit()
  GuiBeginWindow(...)
    GuiAddLabel / GuiAddButton / GuiAddEditBox   (any mix; list order = TAB order)
  GuiShow()                                       <- window becomes visible here
    loop { GuiWaitEvent() ... }
  GuiCloseWindow()
GuiShutdown()
```

Return `-1` for violations: `GuiAdd*` after `GuiShow`, `GuiShow` twice,
`GuiWaitEvent` before `GuiShow`.

## 2. Library bases and LVOs

`ExecBase` is the absolute longword at address `4` (already `EQU`'d in `lib/hardware.i`).

| Symbol | Offset | Library | Registers |
| --- | --- | --- | --- |
| `_LVOOpenLibrary` | -552 | exec | `a1`=name, `d0`=version → `d0`=base |
| `_LVOCloseLibrary` | -414 | exec | `a1`=base |
| `_LVOWait` | -318 | exec | `d0`=sigmask → `d0`=signals |
| `_LVOGetMsg` | -372 | exec | `a0`=port → `d0`=msg or 0 |
| `_LVOReplyMsg` | -378 | exec | `a1`=msg |
| `_LVOForbid` / `_LVOPermit` | -132 / -138 | exec | — |
| `_LVOOpenWindow` | -204 | intuition | `a0`=NewWindow → `d0`=Window |
| `_LVOCloseWindow` | -72 | intuition | `a0`=Window |
| `_LVOPrintIText` | -216 | intuition | `a0`=RPort, `a1`=IntuiText, `d0`=xoff, `d1`=yoff |
| `_LVOAddGList` | -438 | intuition | `a0`=Win, `a1`=Gad, `d0`=pos(-1), `d1`=count(-1), `a2`=0 |
| `_LVORemoveGList` | -444 | intuition | `a0`=Win, `a1`=Gad, `d0`=count(-1) |
| `_LVORefreshGList` | -432 | intuition | `a0`=Gad, `a1`=Win, `a2`=0, `d0`=count(-1) |
| `_LVOActivateGadget` | -462 | intuition | `a0`=Gad, `a1`=Win, `a2`=0 |
| `_LVOModifyIDCMP` | -150 | intuition | `a0`=Win, `d0`=flags |
| `_LVOBeginRefresh` | -354 | intuition | `a0`=Win |
| `_LVOEndRefresh` | -366 | intuition | `a0`=Win, `d0`=complete(1) |
| `_LVODrawBorder` | -108 | intuition | `a0`=RPort, `a1`=Border, `d0`=xoff, `d1`=yoff |

Module-private state (`SECTION gui_data,DATA` — fast RAM, nothing here is DMA'd):

```
gui_int_base    dc.l 0      ; IntuitionBase
gui_gfx_base    dc.l 0      ; GfxBase
gui_window      dc.l 0      ; struct Window *, 0 = closed
gui_rport       dc.l 0      ; Window->RPort   (offset 50), cached at GuiShow
gui_userport    dc.l 0      ; Window->UserPort(offset 86), cached at GuiShow
gui_sigmask     dc.l 0      ; 1 << UserPort->mp_SigBit
gui_int_name    dc.b "intuition.library",0
gui_gfx_name    dc.b "graphics.library",0
```

`GuiInit` opens intuition with `d0 = 37`, then graphics with `d0 = 37`; on the second failure it
must close intuition again before returning `-1`. For Kickstart 1.3 compatibility pass `d0 = 0`
instead — everything in this design exists in V33 except `GFLG_STRINGEXTEND` and `GACT_BOOLEXTEND`,
which are not used.

### 3.3 Window flags

| Name | Hex |
| --- | --- |
| `WFLG_SIZEGADGET` | `$00000001` |
| `WFLG_DRAGBAR` | `$00000002` |
| `WFLG_DEPTHGADGET` | `$00000004` |
| `WFLG_CLOSEGADGET` | `$00000008` |
| `WFLG_SIZEBRIGHT` | `$00000010` |
| `WFLG_SIZEBBOTTOM` | `$00000020` |
| `WFLG_SMART_REFRESH` | `$00000000` |
| `WFLG_SIMPLE_REFRESH` | `$00000040` |
| `WFLG_GIMMEZEROZERO` | `$00000400` |
| `WFLG_ACTIVATE` | `$00001000` |
| `WFLG_NOCAREREFRESH` | `$00020000` |

Generator default: `$0000100E` (`DRAGBAR|DEPTHGADGET|CLOSEGADGET|ACTIVATE`).
Sizeable variant adds `SIZEGADGET|SIZEBRIGHT|SIZEBBOTTOM` → `$0000103F`.

> `WFLG_SMART_REFRESH` is **zero**. Do not OR it in as if it were a bit, and never emit `$40`
> by mistake — that is `SIMPLE_REFRESH` and forces a full redraw on every damage event.

**`GIMMEZEROZERO` is deliberately not used.** It costs a second layer and changes gadget
semantics. Instead the designer canvas origin is already inset by
`(BORDER_LEFT, BORDER_TOP) = (4, 11)`, so emitted coordinates are window-relative and correct at
`OpenWindow` time with no runtime fixup.

| Off | Size | Field |
| --- | --- | --- |
| 12 / 14 | WORD | `wd_MouseY` / `wd_MouseX` (note the order) |
| **50** | APTR | **`wd_RPort`** — for `PrintIText` / `DrawBorder` |

| Off | Size | Field |
| --- | --- | --- |
| 0 | APTR | `gg_NextGadget` (0 terminates the list) |
| 4 / 6 | WORD | `gg_LeftEdge` / `gg_TopEdge` |
| 8 / 10 | WORD | `gg_Width` / `gg_Height` |
| 12 | UWORD | `gg_Flags` (`GFLG_*`) |
| 14 | UWORD | `gg_Activation` (`GACT_*`) |
| 16 | UWORD | `gg_GadgetType` (`GTYP_*`) |
| 18 | APTR | `gg_GadgetRender` → `Border*` |
| 22 | APTR | `gg_SelectRender` (0) |
| 26 | APTR | `gg_GadgetText` → `IntuiText*` |

## 4. What each `GuiAdd*` must build

### 4.1 `GuiAddButton(id, x, y, w, h, caption)`

Allocate the next slot from the static pools and fill:

```
Gadget:  LeftEdge=x  TopEdge=y  Width=w  Height=h
         Flags=$0000 (GFLG_GADGHCOMP)
         Activation=$0003 (GACT_RELVERIFY|GACT_IMMEDIATE)
         GadgetType=$0001 (GTYP_BOOLGADGET)
         GadgetRender=&Border   GadgetText=&IntuiText   GadgetID=id
Border:  LeftEdge=0 TopEdge=0 FrontPen=1 BackPen=0 DrawMode=JAM1 Count=5 XY=&xy
xy:      0,0  w-1,0  w-1,h-1  0,h-1  0,0        ; polyline is NOT auto-closed
IText:   FrontPen=1 BackPen=0 DrawMode=JAM1
         LeftEdge=(w - 8*strlen)/2   TopEdge=(h - 8)/2   IText=caption
```

### 4.2 `GuiAddEditBox(id, x, y, w, h, buf, undo, maxlen)`

**The gadget rectangle of a string gadget is the *text area*, not the frame.** The designer
supplies the outer rectangle, so the runtime converts:

```
Gadget:  LeftEdge=x+2  TopEdge=y+2  Width=w-4  Height=h-4
         Flags=$0000 (add $0200 GFLG_TABCYCLE on V36+)
         Activation=$0001 (GACT_RELVERIFY)
         GadgetType=$0004 (GTYP_STRGADGET)
         GadgetRender=&Border  GadgetText=0  SpecialInfo=&StringInfo  GadgetID=id
Border xy: -2,-2  w-3,-2  w-3,h-3  -2,h-3  -2,-2     ; frame surrounds the text area
StringInfo: Buffer=buf  UndoBuffer=undo  BufferPos=0  MaxChars=maxlen
            all remaining fields zero
```

`maxlen` counts the NUL: a 20-character field needs `maxlen = 21` and 21-byte buffers.

### 4.3 `GuiAddLabel(id, x, y, text)`

No gadget. Store an `IntuiText` plus the draw offsets `(x, y)` and the id. Rendered by
`GuiShow()` and re-rendered on every `IDCMP_REFRESHWINDOW`:

```
    move.l  gui_int_base,a6
    move.l  gui_rport,a0
    lea     label_itext,a1
    move.l  label_x,d0
    move.l  label_y,d1
    jsr     _LVOPrintIText(a6)
```

### 4.4 Static storage budget

No `AllocMem`, no failure path, no leak:

```
GUI_MAX_GADGETS EQU 32
GUI_MAX_LABELS  EQU 32

gui_nw          ds.b 48
gui_gadgets     ds.b 44*GUI_MAX_GADGETS
gui_borders     ds.b 16*GUI_MAX_GADGETS
gui_bordxy      ds.w 10*GUI_MAX_GADGETS      ; 5 points x 2 words
gui_itexts      ds.b 20*GUI_MAX_GADGETS
gui_strinfo     ds.b 36*GUI_MAX_GADGETS
gui_labels      ds.b 20*GUI_MAX_LABELS
gui_label_xy    ds.w  2*GUI_MAX_LABELS
gui_label_id    ds.w    GUI_MAX_LABELS
gui_ngads       ds.w 1
gui_nlabels     ds.w 1
gui_evt_id      ds.l 1
gui_evt_code    ds.l 1
gui_evt_mx      ds.w 1
gui_evt_my      ds.w 1
```

≈4.5 KB of fast RAM. The Python side refuses to export a layout that exceeds these limits.

## 5. The IDCMP event loop

### 5.1 Signal mask, computed once in `GuiShow`

```
MP_SIGBIT   EQU 15          ; MsgPort.mp_SigBit (UBYTE)
WD_USERPORT EQU 86

    move.l  gui_window,a0
    move.l  WD_USERPORT(a0),a1
    move.l  a1,gui_userport
    moveq   #0,d1
    move.b  MP_SIGBIT(a1),d1
    moveq   #1,d0
    lsl.l   d1,d0
    move.l  d0,gui_sigmask
```

### 5.2 `IntuiMessage` offsets

| Off | Size | Field |
| --- | --- | --- |
| 0 | 20 | `im_ExecMessage` (what `ReplyMsg` wants) |
| 20 | ULONG | `im_Class` |
| 24 | UWORD | `im_Code` |
| 26 | UWORD | `im_Qualifier` |
| 28 | APTR | `im_IAddress` (`Gadget*` for GADGETUP/DOWN) |
| 32 / 34 | WORD | `im_MouseX` / `im_MouseY` |
| 36 / 40 | ULONG | `im_Seconds` / `im_Micros` |
| 52 | | `im_SIZEOF` |

### 5.3 `GuiWaitEvent`

```
GuiWaitEvent:
    link    a6,#0
    movem.l d1-d3/a0-a3,-(sp)
.wait
    move.l  ExecBase,a6
    move.l  gui_sigmask,d0
    jsr     _LVOWait(a6)
.drain
    move.l  ExecBase,a6
    move.l  gui_userport,a0
    jsr     _LVOGetMsg(a6)
    move.l  d0,a3
    move.l  a3,d0
    beq.s   .wait                   ; spurious wakeup

    ; ---- snapshot BEFORE ReplyMsg ----
    move.l  20(a3),d1               ; im_Class
    moveq   #0,d2
    move.w  24(a3),d2               ; im_Code
    move.l  28(a3),d3               ; im_IAddress
    move.w  32(a3),gui_evt_mx
    move.w  34(a3),gui_evt_my
    move.l  a3,a1
    jsr     _LVOReplyMsg(a6)
    ; ---- decode from the copies only ----

    move.l  d2,gui_evt_code
    clr.l   gui_evt_id

    btst    #9,d1                   ; IDCMP_CLOSEWINDOW   $200
    bne     .close
    btst    #6,d1                   ; IDCMP_GADGETUP      $040
    bne     .gadup
    btst    #5,d1                   ; IDCMP_GADGETDOWN    $020
    bne     .gaddown
    btst    #21,d1                  ; IDCMP_VANILLAKEY    $200000
    bne     .key
    btst    #3,d1                   ; IDCMP_MOUSEBUTTONS  $008
    bne     .mouse
    btst    #2,d1                   ; IDCMP_REFRESHWINDOW $004
    bne     .refresh
    bra     .drain                  ; unknown class: skip, take the next message

.gadup
    move.l  d3,a0                   ; a0 = Gadget*
    moveq   #0,d0
    move.w  38(a0),d0               ; gg_GadgetID, zero-extended
    move.l  d0,gui_evt_id
    move.w  16(a0),d0
    and.w   #$0007,d0               ; GTYP_GTYPEMASK
    cmp.w   #4,d0                   ; GTYP_STRGADGET?
    beq.s   .is_str
    moveq   #GUI_EVT_BUTTON,d0
    bra     .out
.is_str
    moveq   #GUI_EVT_STRING,d0
    bra     .out

.refresh
    move.l  gui_window,a0
    move.l  gui_int_base,a6
    jsr     _LVOBeginRefresh(a6)
    bsr     gui_redraw_labels
    move.l  gui_window,a0
    moveq   #1,d0
    jsr     _LVOEndRefresh(a6)
    moveq   #GUI_EVT_REFRESH,d0
    bra     .out
```

`.close` / `.gaddown` / `.key` / `.mouse` set `d0` to their class code and fall into `.out`,
which restores registers and returns `d0`.

`im_Code` for `IDCMP_MOUSEBUTTONS`: `SELECTDOWN` `$68`, `SELECTUP` `$E8`, `MENUDOWN` `$69`,
`MENUUP` `$E9`.

## 6. Gotchas — non-negotiable

1. **Copy before reply.** After `ReplyMsg`, the `IntuiMessage` is dead memory owned by
   Intuition. Reading `im_Code` or `im_IAddress` afterwards works 99 times out of 100 and then
   corrupts a gadget pointer under load. This is the single most common failure in this design.
2. **Reply every message.** No early `return` out of the middle of the loop.
3. **Drain before closing, and drain *before* `ModifyIDCMP`.** `GuiCloseWindow` must follow the
   RKM `CloseWindowSafely()` order:
   `Forbid` → `GetMsg`/`ReplyMsg` until 0 → `win->UserPort = NULL` → `ModifyIDCMP(win, 0)` →
   `RemoveGList` → `CloseWindow` → `Permit`.
   `ModifyIDCMP(win, 0)` **deletes the window's UserPort**, so draining after it is a
   use-after-free on a freed `MsgPort`. This is the one legitimate `Forbid` in a
   system-friendly app: a short, bounded critical section required by the documented
   close protocol.
4. **Teardown order is strict:** `RemoveGList` → `CloseWindow` → `CloseLibrary(graphics)` →
   `CloseLibrary(intuition)`. Zero `gui_window`/`gui_rport`/`gui_userport` as you go.
5. **Terminate the gadget list.** The last `gg_NextGadget` must be 0. Zeroed BSS gives this for
   free on the first build; re-terminate explicitly if a form is rebuilt in the same run.
6. **List order matters twice:** hit-test priority for overlapping gadgets (first match wins)
   and TAB cycle order for `GFLG_TABCYCLE`. Emit in the designer's declared order.
7. **`si_Buffer` and `si_UndoBuffer` must be writable** — HAS `data`/`bss`, never a shared
   string literal, never a stack buffer. Plain fast RAM: nothing here is DMA'd by the custom
   chips, so do **not** use `data_chip`/`bss_chip`.
8. **All strings must outlive the window.** Intuition keeps the pointers.
9. **Refresh is your job for anything you drew yourself.** `SMART_REFRESH` redraws gadgets but
   not `PrintIText` labels. If you request `IDCMP_REFRESHWINDOW` you **must** answer it with
   `BeginRefresh` / redraw / `EndRefresh(win, 1)` — ignoring it leaves the layer locked and the
   window unusable.
10. **Prefer non-sizeable windows.** Absolute pixel layout and resizing are fundamentally at
    odds; a resizable form needs a layout engine that does not exist here.
11. **Minimum sizes:** `nw_Width ≥ 90`, `nw_Height ≥ 26`. `nw_TopEdge ≥ 11` or the window opens
    under the screen title. `OpenWindow` returns 0 if the window is larger than the screen.
12. **Gadget ID 0 is reserved** for "no gadget" so `GuiGetEventID() == 0` is unambiguous.
13. **A string gadget `GADGETUP` means "RETURN pressed or tabbed away"** — the buffer is only
    stable at that point.
14. **Workbench launch:** call `WBStartup` first and `WBExit` last (see `lib/wbstartup.s`).
    Failing to reply the WBStartup message hangs Workbench and can get the code unloaded while
    it is still running.
15. **Never touch `$DFF0xx`.** Everything renders through the window's `RastPort`.
